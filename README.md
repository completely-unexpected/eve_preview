# EVE 메인 화면 시안

REA에서 확인한 공개 화면의 배치와 색상을 참고한 독립적인 로컬 시안입니다. 기존 Django 파일과 데이터베이스는 수정하지 않았습니다.

## 확인 방법

`dist/index.html`을 Chrome에서 열면 됩니다. Node.js, Django 서버, 추가 패키지는 필요하지 않습니다.

## 구성

- 상단 메뉴, 시계, 메인 배너
- 수동 전환하는 프로모션 배너 4개와 바로가기
- 소개 카드 4개와 미니게임 카드 12개
- 로그인·회원가입·안내 팝업
- 모바일 화면 대응

메뉴는 메인 페이지 내 해당 구역으로 이동합니다. 실제 게임, 경기 데이터, 로그인, 회원가입, 입출금 기능은 없습니다. 폼 입력은 서버로 보내거나 저장하지 않습니다.

원본 사이트의 로고·사진·배너 파일을 내려받지 않고, CSS와 문자·이모지로 시안용 비주얼을 구성했습니다. 따라서 원본 이미지를 포함한 완전한 복제는 아닙니다.
