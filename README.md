# EVE 웹 프로젝트

기존 `eve_project`와 분리된 로컬 프론트엔드·Django 백엔드 프로젝트입니다.

## 로컬 실행 (PowerShell, 저장소 최상위)

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe backend\manage.py migrate
.\.venv\Scripts\python.exe backend\manage.py runserver
```

이미 가상환경·패키지·DB를 준비했다면 마지막 `runserver` 명령만 실행합니다. 가상환경 활성화 스크립트는 필요하지 않습니다.

- 사이트: http://127.0.0.1:8000/
- 관리자: http://127.0.0.1:8000/admin/

관리자 계정이 없다면 `createsuperuser` 명령으로 해당 PC에서 별도 생성합니다. DB와 계정은 GitHub에 저장되지 않습니다.

`dist/index.html`을 파일로 직접 열어 화면을 볼 수도 있지만, 실제 회원 기능은 개발 서버 주소에서만 동작합니다.

## 회원 기능

- 아이디·닉네임·비밀번호·비밀번호 확인으로 회원가입
- 중복 아이디, 약한 비밀번호, 비밀번호 불일치 검증
- 가입 신청 → 관리자 승인 → 로그인, 로그아웃
- 관리자 회원 목록의 승인 대기·승인 완료·이용 정지 상태, 검색·필터
- 선택 회원 일괄 승인·정지·이용 재개 및 변경 이력
- 정지 시 기존 로그인 세션도 다음 요청부터 차단, 관리자 계정 정지 방지
- Django 세션 쿠키로 새로고침 후 로그인 유지
- 상단 닉네임 표시와 입력 오류 안내
- Django 비밀번호 해시 저장 및 CSRF 보호

닉네임은 필수 입력이며 최대 30자입니다. 닉네임 중복은 허용됩니다. 비밀번호 찾기, 이메일 인증, 로그인 시도 제한, 운영 배포는 아직 구현하지 않았습니다.

API는 `/api/accounts/session/` (GET), `signup/`, `login/`, `logout/` (POST)입니다. POST 입력은 form-urlencoded이며 CSRF 토큰이 필요합니다.

## 화면 기능

메뉴·바로가기, 프로모션 전환, 게임 검색·필터·상세, 이벤트 목록·상세, 카지노 필터, 스포츠 샘플 검색·선택 목록, 뒤로가기·새로고침을 지원합니다. 경기·배당·점수·카지노 분류는 화면 확인용 샘플입니다. 게임 API, 실제 게임 실행, 입출금·베팅·정산은 연결되지 않았습니다.

## 설정·검증

Python 3.14 / Django 6.1.2 / SQLite를 사용합니다. 관리자 언어는 한국어, 서버 시간대는 UTC이며 화면 시계는 서울 시간입니다.

비밀키는 `DJANGO_SECRET_KEY` 환경변수 또는 Git에서 제외한 `backend/.local-secret`에 보관합니다. 로컬 비밀키 파일이 없으면 개발 시 자동 생성합니다. `.venv`, DB, 비밀키는 커밋하지 않습니다.

```powershell
.\.venv\Scripts\python.exe backend\manage.py check
.\.venv\Scripts\python.exe backend\manage.py test accounts
```

회원 테스트는 별도 임시 DB를 사용합니다. 로컬 정적 파일 제공은 DEBUG 모드용입니다. 운영 배포 전에는 정적 파일 제공·HTTPS·배포 설정과 추가 보안 기능을 구성해야 합니다.

## 관리자 회원 관리

새 가입자는 승인 대기 상태로 저장됩니다. 관리자 회원 목록에서 회원을 선택하고 ‘선택한 회원 가입 승인’을 실행하면 로그인할 수 있습니다. 승인된 일반 회원을 정지하거나 정지된 회원의 이용을 재개할 수 있습니다. 관리자·스태프 계정은 이 작업에서 제외됩니다. 기존 활성 회원은 승인 완료, 비활성 회원은 이용 정지로 이관되며 기존 활성 상태는 보존됩니다.

로그인 후 상단 **비밀번호 변경**에서 현재 비밀번호와 새 비밀번호를 입력할 수 있습니다. 변경한 브라우저의 로그인은 유지되고 다른 로그인 세션은 만료됩니다.

로그인 후 상단 **회원정보 수정**에서 닉네임(최대 30자)을 변경할 수 있습니다. 로그인 아이디와 회원 권한은 변경되지 않습니다.

관리자 페이지의 **공지사항**에서 제목·내용을 작성하고 **게시**를 체크하면 사이트의 공지사항 메뉴에 공개됩니다. 상단 고정과 페이지당 20개 목록을 지원하며, 게시하지 않은 공지는 공개 API에서도 숨겨집니다.

**1:1 문의** 메뉴에서 로그인한 회원이 문의를 작성하고 자신의 문의와 답변만 확인할 수 있습니다. 관리자는 관리자 페이지의 **1:1 문의**에서 답변을 저장합니다. 문의 제목 200자, 내용 10,000자, 목록은 페이지당 20개입니다.

관리자 페이지의 **게임 관리 → 게임**에서 게임명·분류·안내·표시 순서·게시 여부를 관리합니다. 기존 12개 샘플 게임을 처음 한 번 DB에 등록하며 이후 관리자가 수정한 내용을 유지합니다. 게시 해제한 게임은 공개 목록과 상세 API에서 숨겨집니다. 실제 게임 제공업체 API는 아직 연결되지 않았습니다.

관리자 페이지의 **이벤트 관리 → 이벤트**에서 제목·내용·요약·배너 문구·아이콘·게시 여부·표시 순서를 관리합니다. 메인 프로모션 배너와 이벤트 목록·상세 화면에 게시된 이벤트가 반영됩니다. 기존 4개 샘플은 최초 DB 생성 시 등록되며 실제 참여 신청이나 혜택 지급은 제공하지 않습니다.

회원 로그인 API는 같은 접속 IP와 아이디 조합에서 5분 내 5회 실패하면 5분간 제한합니다. 성공하면 실패 기록이 초기화되며, 제한 중에는 남은 시간이 안내됩니다. 제한 기록은 DB에 보관되어 서버 재시작 후에도 유지됩니다. 관리자 로그인에는 이 제한을 적용하지 않습니다.

로그인 후 상단 닉네임을 누르면 **내 계정** 화면에서 아이디·닉네임·가입일(한국 시간)을 확인하고 회원정보 수정·비밀번호 변경·내 문의로 이동할 수 있습니다. 로그아웃하면 계정 정보가 숨겨집니다.

관리자 홈의 **관리자 현황 보기**에서 전체 회원(관리자 포함)·승인 대기·이용 정지·전체 문의·답변 대기 문의 수를 확인하고 해당 관리 목록으로 이동할 수 있습니다. 로그인한 활성 관리자에게만 제공하며 각 모델의 조회 권한이 있는 통계만 표시됩니다.

자신의 문의에 읽지 않은 답변이 있으면 상단에 **새 답변 N건**이 표시됩니다. 문의 목록에서는 **새 답변**으로 구분되고 상세 답변을 열면 읽음 처리됩니다. 관리자 답변 수정은 다시 알림을 표시하며 로그인·새로고침·30초 간격·탭 복귀 시 확인합니다. 알림은 사이트 안에서만 표시됩니다.
