# EVE 웹 화면 시안

기존 Django 프로젝트와 분리된 독립적인 로컬 프론트엔드 시안입니다.

## 열기

`dist/index.html`을 Chrome에서 열면 됩니다. 서버나 추가 패키지는 필요하지 않습니다.

## 동작하는 기능

- 상단 메뉴, 홈 로고, 바로가기, 소개 카드의 개별 화면 이동
- 프로모션 배너 앞뒤 전환과 이벤트 상세 연결
- 게임 12개 목록, 이름 검색, 종류 필터, 게임 상세와 이용 안내
- 이벤트 목록·상세·다음 이벤트·목록 복귀
- 카지노 샘플 목록과 라이브·슬롯 필터
- 스포츠·인플레이·E스포츠 샘플 경기 검색·종목 필터·경기 상세
- 샘플 선택 항목 추가·삭제·전체 비우기 (베팅은 실행하지 않음)
- 브라우저 뒤로가기·앞으로가기 및 현재 주소로 새로고침
- 로그인·회원가입 팝업 열기·닫기·Escape
- 서울 시간 시계, 메인 배너 SVG, 모바일 대응

## 아직 연결하지 않은 기능

경기·배당·점수는 고정된 샘플이며 실제 경기 데이터가 아닙니다. 카지노 목록도 시안용 분류입니다. 게임 제공업체 API, 실제 게임 실행, 실시간 데이터, 사용자 인증, DB, 입출금·베팅·정산은 연결되지 않았습니다.

로그인·회원가입 폼은 브라우저 기본 필수 입력 검사 후 안내만 표시합니다. 입력 내용은 저장하거나 전송하지 않습니다. 게임 카드의 상세 화면에서는 API가 미연결임을 표시합니다.

원본 사이트의 이미지나 서버 코드를 복제하지 않았습니다. 화면 배치와 색상을 참고해 CSS, SVG, 문자·이모지로 구성했습니다.
